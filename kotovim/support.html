kotoVim 操作ガイド

0.9.0-rc.23の標準版とLite版に対応しています。文書全体を対象とする操作の範囲は、編集中の入力欄によって決まります。

操作一覧

キー動作
i / v / Esc / Ctrl+[ / F8i でInsert、v でVisual。Esc、Ctrl+[、F8 でNormalに戻る。
h j k l / 0 $ / gg G左・下・上・右、行頭・行末、編集中の欄の先頭・末尾へ移動。
w b e ge / 3w次の単語の先頭、前の単語の先頭、単語の末尾、前の単語の末尾へ移動。3w は3回分の移動。日本語にも対応。
W B E gE空白で区切ったまとまりで移動。句読点も同じまとまりに含む。
[b / ]b / viP diP ciP yiP日本語の前・次の文節の先頭へ移動。iP は文節を対象に選択・削除・変更・コピーできるkotoVim独自の指定。
( / ) / d) c) y)前・次の文の先頭へ移動。日本語の 。 ！ ？ に対応。d) などで次の文の直前まで編集。
f / t / df / dt同じ行で次に現れる文字へ移動し、t はその手前で止まる。df は対象文字を含めて削除、dt は対象文字を残す。
dw cw / de dE / dWカーソル位置から移動先まで削除・変更。de と dE は移動先の単語末を含めて削除。cw は変更後にInsertへ移る。
diw ciw yiwカーソルが内側にある単語全体を削除・変更・コピー。
D d$ / C c$ / A行末まで削除、行末まで消してInsert、行末でInsert。
dd yy / p P / o O行を削除・コピー。行単位でコピーした内容は p で下、P で上に貼り付け。o / O は下／上に行を作ってInsert。
dG cG yG現在行から編集中の欄の末尾まで、行単位で削除・変更・コピー。
Visual の I / A選択した各行の行頭／行末に同じ文字列を挿入。
r / :%s/旧/新/g1文字を置換。日本語は r → F2 で入力。一括置換コマンドは、対応欄で一致する文字列をまとめて置換。
u / Rアプリの元に戻す／やり直すを実行。

日本語の文や文字へ移動する

例文をメモ帳に貼り付けます。Normalで行頭から ) を押すと「結果」の先頭へ、続けて ( を押すと行頭へ戻ります。

同じ行の句点へ進むには f、F2 の順に押し、検索窓に「。」を入力します。IME変換を使った場合は文字を確定してから、Enter で検索を実行します。ひらがなや漢字も1文字ずつ指定できます。半角英数字は f のあとに直接押せます。

IMEとモード表示

Insertや置換窓で左Altを単独で押すと、Microsoftの日本語IMEを切り替えられます。通知領域ではこの切り替えの有効・無効や、Ctrl+J / Ctrl+M をEnterにする設定を選べます。

通知領域の「モード表示」で、詳細、短い1行、N / I / V、非表示から選べます。「表示位置」でアプリの下部とカーソル付近を切り替えられます。

アプリ別の使い方と確認範囲

  • メモ帳、Word、新しいOutlookでは、メモ帳やWordの文書本文、Outlookのメール作成本文をクリックします。各本文でのモード切り替え・移動は旧版で確認済みです。
  • Excelでは、シート上でNormalの h j k l がセル移動になります。セル内の文章は F2 で編集を開始し、F8 でNormalに切り替えます。セル移動と文字編集は旧版で確認済みです。
  • PowerPointでは、テキストボックスや表のセル内の文字をクリックします。F8 でNormalに切り替えられます。両方での文字編集は旧版で確認済みです。
  • Chromeのテスト用入力欄では、文や単語末への移動、行単位の削除、句点の検索を確認しました。サイトや入力欄の実装によって使える操作が異なります。

Office全アプリでの最新版の通し試験と、Windows 10実機での確認は未実施です。

確認とFAQ

新しいバージョンを確認するには？

通知領域の「更新」から「更新を確認」を選べます。既定では起動の15秒後と、起動中は24時間ごとに一般公開版を確認します。新しい版の通知をクリックするとダウンロード欄が開きます。同じ版の通知は一度です。「更新を自動で確認して通知」のチェックを外すと自動確認を停止できます。

ファイルを確認するには？

Get-FileHash -LiteralPath .\kotoVim.exe -Algorithm SHA256

Lite版はファイル名を kotoVim_lite.exe に変えて実行します。入手したテスト版の SHA256.txt に掲載されている値と照合します。ブロックされた場合はWindowsや勤務先の承認手順を使用してください。

Normalに切り替わらないときは？

通知領域で起動とバージョンを確認し、書き込み可能な欄をクリックします。IMEで変換中の文字があれば確定してから F8 を試してください。パスワードや読み取り専用欄は対象外です。必要に応じて通知領域で一時停止できます。

Commands

This guide covers the Standard and Lite editions of 0.9.0-rc.23. Document-level commands operate within the active editable field.

KeysBehavior
i / v / Esc / Ctrl+[ / F8Enter Insert with i or Visual with v. Return to Normal with Esc, Ctrl+[, or F8.
h j k l / 0 $ / gg GMove left, down, up, or right, to either end of the line, or to the start or end of the active field.
w b e ge / 3wMove to the next word start, previous word start, word end, or previous word end. 3w applies the motion three times. Japanese words are supported.
W B E gEMove by groups of non-whitespace characters, including punctuation in the same group.
[b / ]b / viP diP ciP yiPJump to the previous or next Japanese phrase start. Use kotoVim’s iP text object to select, delete, change, or yank a phrase.
( / ) / d) c) y)Move to the previous or next sentence start, including sentences ending with 。, ！, or ？. Use d), c), or y) to act on text up to the next sentence.
f / t / df / dtFind the next occurrence of a character on the current line. t stops just before it. df deletes through the target and dt stops before it.
dw cw / de dE / dWDelete or change text from the caret using a motion. de and dE include the final character of the word or WORD. cw enters Insert.
diw ciw yiwDelete, change, or yank the whole word under the caret.
D d$ / C c$ / ADelete to the end of the line, change to the end of the line, or enter Insert at the line end.
dd yy / p P / o ODelete or yank a line. Paste linewise text below with p or above with P. o / O open a line below or above and enter Insert.
dG cG yGDelete, change, or yank whole lines from the current line to the end of the active field.
Visual I / AInsert the same text at the start or end of each selected line.
r / :%s/old/new/gReplace one character. For Japanese text, press r then F2. The bulk replacement command replaces all matches of a literal string in supported fields.
u / RRun the app’s Undo or Redo.

IME and mode indicator

Tap left Alt in Insert or a replacement dialog to toggle the Microsoft Japanese IME. The tray menu lets you turn this shortcut on or off and optionally map Ctrl+J / Ctrl+M to Enter.

In the tray menu, choose Detailed, Compact, Badge (N / I / V), or Hidden under Mode indicator. Select Below the app or Near the caret under Indicator position.

Using kotoVim in different apps

  • Click inside a document in Notepad or Word, or inside the message body when composing in new Outlook. Mode switching and motions were verified there in earlier builds.
  • In the Excel grid, Normal-mode h j k l move between cells. Use F2 to edit cell text and F8 to switch to Normal. Cell navigation and text editing were verified in earlier builds.
  • In PowerPoint, click inside the text of a text box or table cell. Use F8 to switch to Normal. Text editing in both was verified in earlier builds.
  • Sentence and word-end motions, linewise deletion, and Japanese punctuation searches were verified in a Chrome test field. Available commands vary by site and field.

Full testing of the current build across Office apps and hands-on Windows 10 testing are pending.

Verification and FAQ

How do I check for an update?

Open Updates in the tray and select Check for updates. By default, kotoVim checks for public releases 15 seconds after startup and once every 24 hours while running. Click the notice to open the downloads section. Each version is announced once. Uncheck Automatically check and notify to turn these checks off.

How do I verify the file?

Get-FileHash -LiteralPath .\kotoVim.exe -Algorithm SHA256

Use kotoVim_lite.exe in the command for the Lite edition. Compare the result with the matching value in the test release’s SHA256.txt. If blocked, use the approved Windows or workplace review process.

Why does Normal mode not activate?

Check that kotoVim is running and verify its version in the tray. Click an editable field, confirm any IME composition, and try F8. Password and read-only fields are excluded. Use Pause in the tray when needed.
