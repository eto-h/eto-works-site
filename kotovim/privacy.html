プライバシー

アプリと製品ページ

編集のためキーボードイベントや文字列を端末内で処理します。キー入力や文書のログは保存しません。OSとアプリのクリップボードを使用します。広告SDKとアクセス解析は使用しません。

更新確認では、ETO Worksの公開バージョン番号をHTTPSで取得します。配信元のGitHub Pagesには接続元IPアドレスなどの通常の接続情報が伝わります。入力内容・文書・使用中のバージョンは送信しません。自動確認は常駐メニューで無効にできます。初回案内の記録、更新通知の設定、通知済みバージョンは %LOCALAPPDATA%\kotoVim に保存します。

製品ページには追跡タグと独自Cookieを置かず、GitHub Pagesを利用します。

GitHubのプライバシー声明

Privacy in English

Key events and text are processed on-device. The app does not log keystrokes or documents and does not use an advertising SDK or telemetry. Clipboard actions use the operating system and host app.

Update checks fetch a public version number from ETO Works over HTTPS. GitHub Pages receives ordinary connection information such as the source IP address. Checks do not send typed text, documents, or the installed version. Automatic checks can be turned off in the tray menu. The welcome marker, update preference, and last notified version are stored in %LOCALAPPDATA%\kotoVim.

The product page uses GitHub Pages and contains no tracking tags or custom cookies. Support email is sent by the user through their mail app.
