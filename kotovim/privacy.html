プライバシー

アプリと製品ページ

編集のためキーボードイベントや文字列を端末内で処理します。キー入力・文書のログ、データの送信、広告SDK、アクセス解析はありません。初回案内を表示した記録は %LOCALAPPDATA%\kotoVim\welcome-* に保存します。OSとアプリのクリップボードを使用します。製品ページには追跡タグと独自Cookieを置かず、GitHub Pagesを利用します。

GitHubのプライバシー声明

Privacy in English

Key events and text are processed on-device. There is no key or document logging, network transmission, advertising SDK or telemetry. A welcome marker is stored for each edition in %LOCALAPPDATA%\kotoVim\welcome-*. Clipboard actions use the operating system and host app. The product page uses GitHub Pages and contains no tracking tags or custom cookies. Support email is sent by the user through their mail app.
