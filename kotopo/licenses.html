ライセンス・配布情報

Windows 版

kotopoのWindows用実行ファイルは、eto works が KotoPointer の名称で無料配布しています。対象バージョンは v0.6.0 です。

GitHubの公式リリースとファイル情報

使用しているソフトウェア

キーボード操作とマウス入力には Windows API、クリック候補の取得には Windows UI Automation、画面表示には .NET Framework を利用しています。これらはWindows環境にある機能を呼び出しています。英字ヒントは独自実装です。

Distribution and software notices

eto works distributes this Windows utility as KotoPointer.exe. Version 0.6.0 calls Windows APIs, UI Automation and the .NET Framework installed on your PC. Click hints are implemented in the app. The official release above provides the executable and its file details.
