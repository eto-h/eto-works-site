# ADRIFT Web画像の出典

公開日 2026年11月22日。すべてeto worksのADRIFT用素材またはゲームの実画面。ゲームの画像・フォントの表示は[ライセンス](licenses.html)を参照。

| 公開ファイル | 元素材 | Web掲載時の処理 |
| --- | --- | --- |
| `assets/flight-city.webp` | eto worksがiPhoneで撮影したADRIFTの市街地のゲーム画面 | ゲーム内の1フレームを抽出し、540×1170に縮小、WebP化 |
| `assets/flight-result.webp` | 同じiPhone版の結果画面。距離・時間・スコア・通常リトライ | 同上 |
| `assets/flight-road.webp` | iPhone版の幹線道路の実画面 | 540×1170に縮小、WebP化 |
| `assets/how-to-play.webp` | iPhone版の操作説明の実画面 | 540×1170に縮小、WebP化 |
| `assets/riverbank-hero.webp` | 同サイト既存のADRIFT渓流背景 `assets/Riverbank.png` | 1800×600に縮小、WebP化 |

公開画像はゲーム内の画面と背景アートを使用している。録画本体や審査資料をサイトに掲載していない。
